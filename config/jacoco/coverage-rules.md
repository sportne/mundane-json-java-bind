# JaCoCo Coverage Rules

Active thresholds:

| Aggregate line | Aggregate branch | Per-file line |
|---:|---:|---:|
| 60% | 40% | 40% |

Modules with no compiled production classes skip JaCoCo verification.

The project uses one shared threshold set for every Java project. Keep this file
and `docs/verification/coverage-policy.md` aligned when changing coverage
policy.
